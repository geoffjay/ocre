# Concepts

concepts for the ocre project.

* [ocre product vision](product-vision.md) - what ocre is: a standalone, interactive, collaborative code review system for humans and AI agents.
* [Human code review capacity](research/code-review-capacity.md) - empirical evidence on human review limits and the volume problem.
* [AI review noise](research/ai-review-noise.md) - evidence that agent review output exceeds human capacity, and mitigation patterns.
* [Collaborative review prior art](research/collaborative-review-prior-art.md) - standalone tool history, multiplayer topologies, and the confirmed live-review gap.
* [Agent participation model](research/agent-participation.md) - how user-owned agents become live review participants: desktop bridge, BYO runtime and credentials, MCP/ACP composition.
* [Comment model](design/comment-model.md) - the first-class data model: comment anchors, authorship, verdicts, cross-references.
* [Agent governance constraints](design/agent-governance.md) - volume-control requirements for agent participants.
* [Core-loop spike report](design/core-loop-spike.md) - what the roomd + ocre-bridge prototype proved end-to-end.
* [Shared substrate](design/shared-substrate.md) - proposal for the common library ocre and lore share; the boundary between substrate and app.
